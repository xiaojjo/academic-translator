# 学术翻译 / Academic Translator

DeepSeek Harness（DSH）论文翻译插件：左侧栏「论文翻译」面板 + Agent 工具，提供中英对照的翻译工作台。

**核心能力**

- 可勾选灌入的技能（skill 正文进系统提示词）与论文私有术语表
- 整段 / 逐句两种翻译粒度，随时切换、修改互通
- 中英对照阅读（对照 / 仅译文 / 仅原文）
- 术语全文统一：术语表硬约束 + 译后逐段回查，违规术语在原文中标红并提示应译为
- 原文可改：逐句模式改一句只影响该句，整段模式改一段
- AI 评分：模型扮演期刊母语编辑，五维加权打分，修订需人工接受/拒绝
- 导出 Markdown 对照稿
- 论文列表支持拖动排序
- 浅色 / 深色主题自适应

## 安装

### 方式一：命令行安装（推荐）

也可以装本地目录（`link:` 跟随源码改动，`file:` 是复制一份）：

```bash
# 从本地目录安装（把仓库 clone 或下载解压后）
dsh plugin --profile desktop add link:C:\path\to\academic-translator
dsh plugin --profile desktop add file:C:\path\to\academic-translator
```

安装后**刷新 DSH 页面**，左侧栏出现「论文翻译」图标即成功。

### 方式二：让 AI 帮你装（从 GitHub 下载并安装）

直接在 DSH 会话里对 AI 说：

> 请从 GitHub 下载并安装论文翻译插件：先 clone https://github.com/xiaojjo/academic-translator 到本地任意目录，然后用 plugin_manager 的 install_bundle 安装该目录，安装完启用并提醒我刷新页面。

AI 会自动完成：`git clone`（或下载 zip 解压）→ `plugin_manager` 安装 → 启用 → 提示刷新。

> 说明：本插件无需构建步骤；数据保存在本机 `~/.dsh/data/paper-translator/`，不上传任何服务器。翻译走你当前 DSH 会话配置的模型路由。

## 快速上手（5 分钟）

1. **建论文**：左侧栏点「论文翻译」图标 → 「论文」页 → **新建论文**，粘贴英文原文（空行自动分段），方向选「英→中」。
2. **（可选）维护术语表**：「术语」页点 **提取术语**（AI 从原文提取专业词）或直接手写，每行格式 `原文=译名`，例如 `photosynthesis=光合作用`。术语表全局共用，所有论文立即生效。
3. **（可选）勾技能**：「技能」页勾选要注入翻译的技能（如论文写作规范），技能正文会进系统提示词。
4. **翻译**：顶栏点 **翻译未完成部分**。整段模式一段一段翻；逐句模式一句一句翻。术语违规会在译后自动修正。
5. **校对**：
   - 违规术语在原文里**标红**，译文侧提示「“原词” 应译为 “译名”」；
   - 点卡片 **编辑** 可手改译文；点 **改原文** 修正原文后重译；
   - 改了术语表后点顶栏 **术语回归 N**，把新术语补回已译段落。
6. **评分**：顶栏 **全部评分**（模型按忠实/术语/语体/流畅/格式五维打分），卡片下方逐条 **接受 / 拒绝** AI 修订建议。
7. **导出**：顶栏「⋯」菜单 → **导出**，得到 Markdown 对照稿（含术语表与待处理建议）。

## 卸载

**插件** 页找到「论文翻译」条目 → 移除（Remove）即可；本地数据 `~/.dsh/data/paper-translator/` 不会被自动删除，需要的话手动清理。
