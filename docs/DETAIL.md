# 论文翻译

中英互译的对照工作台。入口在左侧栏「论文翻译」图标，也可从 **设置 → 论文翻译** 打开同一界面。

## 界面

- 顶栏：论文标题、方向（英→中 / 中→英）、粒度（整段 / 逐句）、显示（对照 / 译文 / 原文）、「⋯」菜单（全部重译、全部评分、导出、清空、删除）。没有可评分的译文时「全部评分」置灰。
- 左侧四个标签页：
  - **论文** — 新建与切换，显示每篇的方向与进度。
  - **术语** — 全局术语表：提取或手写，逐条启停，批量导入。
  - **技能** — 勾选要注入翻译的技能。
  - **模型** — 选提供方与模型、每批片段数、思考强度。思考强度档位来自模型真实元数据，模型不支持时下拉禁用。
- 正文每段一张卡片：左原文、右译文。原文侧有「改原文」，译文侧有「编辑 / 重译 / 评分」；评分结果（分数、问题、建议修改、接受 / 拒绝）显示在卡片下方。
- 左侧栏顶部「« / »」可收起成窄轨道、再展开。

## 术语表

**全局共用一份**：所有论文（含未创建的）立即生效；「提取术语」的新词自动并入；旧版按论文保存的表首次加载时自动合并。没打开论文时也可编辑；工具动作 `glossary` 传 `merge: true` 表示追加而非覆盖。

术语是契约，三道保证：

1. **翻译时**：译名以 `原文 => 译名` 写进系统提示词，要求逐字符照用、不得一词多译。
2. **译后强制**（`strictTerms` 默认开）：原文含术语而译文缺译名时，让模型只给替换对 `{from, to}`，程序自己执行替换再校验，最多 3 轮。只采纳 `to` 恰为表内译名、`from` 确在译文中的对，模型无法借机改写别处。
3. **词表变更后**：顶栏「术语回归 N」把新增或改动的术语补回已有译文；「由整段拆分」的句子没有独立译文，会直接修其派生的整段译文。

- 修不好的如实标「术语未统一」，顶栏显示「N 段术语待修」——程序不编造译法；每次自动修正标「已按术语表修正」。
- **标红**：违规段落的原文中，该术语每次出现标红加粗，译文侧提示「“原词” 应译为 “译名”」；修正成功后红标消失。
- **匹配规则**：中文按子串；英文按词边界，接受规则复数（ectotherms = ectotherm）与连字符 / 空格互换（trade off = trade-off），因此 range 不会匹配 range shift。

## 编辑原文

- 卡片「改原文」编辑的正是卡片显示的文本：整段模式是一整段，逐句模式是单独一句。保存后旧译文清空，点「翻译未完成部分」重译。
- 逐句模式改一句只清这一句的译文与评分，同段其他句子保留；整段模式清整段。
- 只改错别字可用工具动作 `editSource`（段落传 `segmentId: "p1"`、单句传 `"p1:s2"`）加 `keepTranslation: true` 保留旧译文。

## 整段 / 逐句

两种粒度是同一份译文，随时切换、修改互通：

- 整段切逐句：译文按句位置拆分、一句对一句显示，无需重译；未单独翻译的句标「由整段拆分」。
- 逐句里的翻译、手改、接受修订、术语回归会自动并回整段：只替换改动的那一句。
- 再改整段时，旧的逐句覆盖清空、全部句子按句位置重新派生。
- 英文切分避开 `et al.`、`Fig. 2`、`0.05` 这类假句末；中文按 `。！？` 切分并照顾引号括号。中英句数不一致时，多出的原文句留空待译。

## 评分

- 模型扮演严格的期刊母语编辑，五维加权：忠实 30 / 术语 25 / 语体 20 / 流畅 15 / 格式 10。
- 分数如实反映模型判断，程序不改分、不设上限；修订不自动生效，必须点「接受 / 拒绝」。
- 颜色：90+ 绿，70–89 黄，<70 红。

## 使用流程

1. 「术语」页维护全局术语表（提取术语或批量导入，每行 `原文=译名`）。
2. 「论文 → 新建论文」，粘贴原文（空行分段），选方向。
3. 可选：勾技能、固定模型、在「给翻译 AI 的约束」写全局要求（只作用于翻译，不影响评分）、选思考强度。
4. 「翻译未完成部分」；术语违规在翻译后自动修正。
5. 原文有误在卡片「改原文」里改，保存后重译；之后改了术语表就点「术语回归 N」。
6. 「全部评分」后在卡片逐条「接受 / 拒绝」；「⋯」导出对照稿或纯译文稿（含术语表与待处理建议）。

## 数据与限制

- 每篇论文存于 `DSH_PROFILE_DIR/data/academic-translator/projects.json`（无该变量时退到 `~/.dsh/data/…`）；旧版单方向数据自动归入「英→中」。
- 双向翻译独立保存，切换方向不覆盖另一方向。
- 技能来自 Host skills 服务与磁盘 `SKILL.md`（工作区 `.dsh/skills`、`.agents/skills`、用户目录、DSH 内置），服务优先。
- 模型路由跟随会话默认，也可固定；默认路由不可用会明确报上游错误。
- 重新导入原文会按 p1…pn 重新分段，同段号旧译文被覆盖；`addParagraph` / `deleteParagraph` 增删段落，删段重新编号并清空该文旧译文、评分与术语记录。
- 不使用 `translator` 服务：它只做纯文本翻译，带不了提示词、技能与术语表。
- 术语回查是字面匹配，不做语义判断；意译、同义替换可能漏报。自动修正只做精确子串替换，修不好的段落保留「待修」，不会被强改。
